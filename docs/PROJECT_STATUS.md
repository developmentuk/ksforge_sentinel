# KSForge Sentinel Project Status

## Current milestone

Version 0.1.0 — Foundation and KSForge identity integration.

## Product model

KSForge is the source of truth for player identities, alliance records, kingdom memberships and published content. KSForge Sentinel provides a Discord-native interface to the same platform.

## Current priorities

1. Establish the original Discord bot application and command framework.
2. Define secure service-to-service API contracts with ksforge.app.
3. Implement Discord-first registration and Forge account linking.
4. Connect players and alliances to the shared KSForge directory.
5. Add published content commands for heroes, events and gift codes.
