# Roadmap

## v0.1 Foundation

- Original TypeScript bot foundation
- Discord command registration
- Forge service client with runtime contract validation
- `/forge about`, `/forge status`, `/forge register`, `/forge link`
- `/hero lookup`, `/event today`, `/giftcode active`
- Health endpoint, structured logging, tests and CI

## v0.2 Identity and Alliances

- Completed Forge OAuth/link callback
- Player registration and verification state
- `/player profile`
- `/alliance register`, `/alliance join`, `/alliance members`
- Forge Alliance Command Centre integration
- Discord role-to-alliance permission mapping

## v0.3 Notifications

- Event subscriptions
- Gift-code alerts
- Alliance-configurable channels
- Idempotent scheduled delivery
- Per-user and per-server locale preferences

## v0.4 Operations

- Attendance and event registration
- Bear Trap and alliance schedule tools
- Officer workflows and audit history
- Transfer and recruitment directory integration

## v0.5 Intelligence

- Hero comparisons and synergies
- Recommended formations
- Progression guidance
- KvK preparation assistant
- Deep links to Creator Hub content
